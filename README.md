# Web Programming - Assignment 2

## File organization

The project has one HTML file and two CSS files. The HTML file contains the six boxes and the CSS files are used for the two different styles.

- `index.html` - HTML structure
- `styleA.css` - Style A
- `styleB.css` - Style B

To switch between the two styles, I change the CSS file name in the link element in `index.html`.

## Challenges

The main challenge was using the same HTML structure for two different layouts. I used Flexbox for the box layouts and fixed sizes so the boxes keep their required dimensions when the window is resized.

I also used `white-space: nowrap` in Style B so the first five boxes stay on the same line.

No JavaScript or external libraries were used.
